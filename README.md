# 🔥 Exercise Calorie Burn Prediction

A Machine Learning and Artificial Neural Network based web application that predicts calories burned during exercise.

## 🚀 Features

- Predict estimated calories burned
- Uses exercise and body-related inputs
- Artificial Neural Network (ANN) model
- Data preprocessing using StandardScaler
- Streamlit web interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Streamlit
- Joblib

## 📊 Input Features

- Gender
- Age
- Height
- Weight
- Exercise Duration
- Heart Rate
- Body Temperature
- BMI

## 🤖 Model

The application uses a trained Artificial Neural Network (ANN) regression model to estimate calories burned.

## 🌐 Deployment

The application is deployed using Streamlit Community Cloud.
